First installation

  1. Download the certificate trust bundle. Verify the certificate against the project's installation guidance before trusting it. Follow your organization's software policy.
  2. Extract the bundle, then run Import-SigningCert.ps1 in an administrator PowerShell window. It imports the public certificate into LocalMachine\TrustedPeople.
  3. Download and open EXOKit.appinstaller with Windows App Installer to install EXOKit and register the update feed.

EXOKit uses a self-signed certificate. Only trust it after verifying its source. Installing the MSIX directly does not enroll the app in feed-based updates.

Already installed?

Enrolled installations check for updates on launch and in the background. Keep the same update feed; a new installer download is not needed for each release.

For EXOKit's manual Check for Updates command, save the update-feed URL in Settings. This setting alone does not enroll Windows in automatic updates.

Upgrading from v1.0.30 or earlier? Back up your settings and follow the publisher migration instructions before installing.
